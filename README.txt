Структура:
  index.html          каркас страницы
  css/styles.css      все стили
  js/config.js        ключи Supabase (SB_URL / SB_KEY)
  js/auth.js          вход/регистрация
  js/adaptive.js      авто-масштаб
  js/01..10-*.js      ядро плеера: audio, ui, web-поиск, youtube, биты, события, vibe, init
  js/20..24-*.js      настройки интерфейса, иконки, профиль, шторка/экран блокировки
  js/30-fixes.js      исправления: один источник звука, фон, звонки
  js/31..33          скачивание мировых треков, режим «окно приложения», окно разрешений при входе
  android/            отдельная раскладка для Android (грузится только там)
Порядок подключения скриптов в index.html менять нельзя.
Рядом с index.html должны лежать manifest.webmanifest, sw.js, icon-192.png, icon-512.png (как раньше).
