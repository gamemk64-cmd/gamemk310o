# v11 — голосовое управление

- Новый модуль `voice.js` заменил старую кнопку «Голос» (старый код отключён).
- Обращение по имени (по умолчанию «Вась», меняется), варианты написания настраиваются.
- Тихие звуковые сигналы: услышал имя / команда выполнена / не понял / вкл-выкл. Три стиля, регулируемая громкость.
- Пока слушает, музыка приглушается (можно говорить вполголоса).
- «Назад» теперь всегда переключает на предыдущую песню (в режиме перемешивания — на реально предыдущую). «Сначала / заново» — начало текущей.
- Перемотка: «перемотай на 20 секунд», «назад на минуту», «на 1:30», «на середину».
- Громкость числом: «громкость 5», «звук на половину».
- Поиск голосом: «Вась, найди …» — сначала в моей музыке, потом YouTube/Audius.
- Все фразы команд редактируются, команды можно выключать, для любой можно разрешить работу без имени.
- Настройки: шестерёнка рядом с кнопкой «Голос» или правый клик → «Голосовое управление…».
- «Продолжить / пауза» теперь корректно работают и с YouTube-треками.

## Интеграция (исправления)
- `voice.js` теперь реально подключён в `index_lyrics_auto.html` (раньше файла не было в странице).
- Приглушение музыки (`voiceG`) добавлено в `applyVol` и `ytVol`, иначе музыка не становилась тише.
- Старая кнопка «Голос» (v7) отключена, чтобы не дублировалась.
- Больше фраз по умолчанию: пауза, продолжить, дальше, назад, сначала, громче, тише; «на 1:30», «к началу», «из моей музыки».


## v11.1 — голосовой музыкальный режим
- Добавлены локальные голосовые ответы через SpeechSynthesis API браузера, без отдельного AI/API для озвучки.
- Музыка автоматически приглушается на время голосового ответа.
- Распознавание игнорирует собственный голос помощника, чтобы он не запускал команды сам на себя.
- «поставь сердечко», «лайкни», «убери сердечко».
- «добавь в плейлист», «добавь в плейлист <название>»; если плейлистов нет, создаётся новый.
- Сохранился мировой поиск и запуск найденной музыки голосом.
- Сохранились существующие команды паузы, продолжения, следующего/предыдущего, громкости, перемотки и караоке.
