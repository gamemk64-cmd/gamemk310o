# MusicPlayer — Smart Voice (ИИ-собеседник)

## Что добавлено
- Плавающая кнопка ИИ и компактный мобильный чат в тёмно-золотом стиле.
- Свободный текстовый разговор через OpenAI Responses API с контекстом последних 12 реплик.
- Голосовой ввод: браузер записывает короткий фрагмент, backend распознаёт его через `gpt-4o-mini-transcribe`. Нажми микрофон, скажи фразу, затем нажми кнопку остановки.
- Естественная озвучка ответа через `gpt-4o-mini-tts`. Музыкальный плеер не заменяется аудио помощника: голос проигрывается отдельным audio-элементом; браузер/Android всё ещё может изменить громкость или аудиофокус.
- API-ключ хранится только в переменных окружения backend; фронтенд его не получает. Ограничение частоты запросов, размер аудио до 12 МБ, ограничение длины сообщений и базовая проверка Origin.

## Важно
Это разговорный ИИ, но пока он **не управляет кнопками плеера**. Он честно объяснит это, если попросить переключить трек. Для реального управления нужен отдельный безопасный слой команд, связанный с API самого плеера.

## Развёртывание backend
Требуется Node.js 20+ и HTTPS для сайта/микрофона. В папке `backend` есть `Dockerfile`.

1. Создай backend-сервис из папки `backend` на поддерживающем Node/Docker хостинге.
2. Установи переменные окружения из `backend/.env.example`: обязательно `OPENAI_API_KEY` и `ALLOWED_ORIGIN`. Не клади ключ в HTML/JS, Git или публичный архив.
3. `ALLOWED_ORIGIN` должен быть точным origin сайта, например `https://music.example.com`, без пути и без завершающего `/`.
4. Запусти `npm install` и `npm start` (или используй Dockerfile). Проверь `https://АДРЕС-БЭКЕНДА/health`: должно вернуться `{"ok":true,"configured":true}`.
5. В корневом `smart-voice-config.js` укажи адрес backend: `window.SMART_VOICE_CONFIG = { apiBase: 'https://your-backend.example.com' };` — обязательно HTTPS, без `/` в конце. Это публичный URL, не секрет.
6. Загрузи весь обновлённый корень сайта на хостинг. Открой сайт через HTTPS и обнови его.

## Стоимость и лимиты
Запросы к ИИ, распознавание речи и генерация голоса оплачиваются отдельно по тарифам API. Включи лимиты расходов у провайдера и при необходимости настрой `express-rate-limit`. Публичный сайт может быть доступен всем посетителям; для продакшена добавь пользовательскую авторизацию или проверку сессии, иначе любой посетитель может расходовать лимит backend. Встроенный лимит по IP — лишь базовая защита.

## Android и звук
- Микрофон требует HTTPS и явного разрешения пользователя.
- Голос записывается только после нажатия кнопки; автоматического постоянного прослушивания нет.
- Android/браузер/другие приложения могут сами приглушать звук при захвате микрофона. Веб-сайт не может гарантировать непрерывную музыку на каждом устройстве.
- Если голос не воспроизводится автоматически, коснись страницы/кнопки ещё раз: мобильные браузеры иногда требуют жест пользователя для запуска аудио.

## Быстрая локальная проверка backend
```bash
cd backend
cp .env.example .env
# Заполни OPENAI_API_KEY и ALLOWED_ORIGIN в .env
npm install
npm start
```
Открывай фронтенд через локальный HTTPS/хостинг, а не `file://`. Не коммить `.env`.
