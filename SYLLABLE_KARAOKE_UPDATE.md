# Обновление караоке: подсветка по слогам и буквам

- Каждое слово разбивается на приблизительные слоги; внутри слога символы подсвечиваются по очереди в соответствии с рассчитанным интервалом слова.
- Используются часы текущего источника воспроизведения; время не накапливается по числу кадров.
- Если у источника есть точные метки слов, они определяют общий интервал слова. Внутренние интервалы букв/слогов всё равно являются оценкой, пока источник не предоставляет метки слогов.
- Для обычного LRC без меток слов и TXT разбивка и темп подсветки приблизительные. Это не фонетический анализ и не распознавание вокала.
- Добавлены тесты деления кириллических и английских слов, безопасного HTML-рендера и сохранения пробелов.

## Темп подсветки подстраивается под песню
- Для LRC с таймингом строк считается скорость пения (слогов/сек) по каждой строке и её соседям (окно ±3 строки, 70-й перцентиль). Быстрые куплеты подсвечиваются быстро, медленные припевы — медленно.
- Строка больше не растягивается на всю паузу до следующей: если после неё идёт проигрыш, подсветка заканчивается раньше и показывается «♪ Пауза».
- Убрано замедление в начале слова (линейный прогресс внутри слова).
- Для текста без таймингов (plain/TXT) и для точных меток слов поведение не менялось.

## Версия «идеальный тайминг»

1. **Лучший источник вместо первого.** Первая группа каталогов (YouTube ID, название, LRCLIB, Apple Music, Better Lyrics) опрашивается одновременно. Результаты оцениваются: метки слов > метки строк > без таймингов, плюс проверка, что таймлайн вписывается в длину трека. Если тайминг только построчный, в фоне доопрашиваются дополнительные каталоги, и при находке тайминга по словам текст заменяется на более точный. «Другой источник» теперь переключает между уже найденными вариантами.
2. **Сдвиг для каждой песни отдельно** (`karaoke-offset:<id>`); старый общий сдвиг используется только как значение по умолчанию. Кнопка «Сброс».
3. **🎯 Разметить тапами**: пробел (или большая кнопка) в момент начала строки/слова; режимы «по строкам» / «по словам», скорость 0.5×/0.75×, отмена тапа ⌫, Esc — выход. Сохраняется как LRC с метками слов навсегда для этой песни (компенсация реакции 120 мс; сдвиг песни сбрасывается в 0).
4. **Внешний вид:** плавная заливка каждой буквы вместо скачков, подсветка следующей строки заранее, «прошедшие» строки всегда полностью залиты (в том числе после перемотки), авто-стиль по темпу песни (быстрая → Club, медленная → Dream).
5. **Исправлено:** слово с меткой в LRC заканчивалось через 1 с независимо от следующей метки; кнопка «Исправить текст» склеивала строки литералом `\n` и теряла метки слов.
